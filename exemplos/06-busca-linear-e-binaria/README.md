# Busca linear × busca binária

**Modo:** ▶ Executar

## O que este exemplo mostra
- **Busca linear**: olha um por um — funciona em qualquer vetor.
- **Busca binária**: só funciona em vetor **ordenado**; a cada passo descarta metade do vetor.
- O programa conta as comparações de cada uma para você ver a diferença.

## Como usar
**▶ Executar** e digite valores para procurar (ex.: `73`, depois `4`, que não existe).

## Experimente
- No **🐞 Depurar**, pare dentro de `buscaBinaria` e acompanhe `ini`, `meio` e `fim` a cada F10.
- Aumente `N` para 1000 e compare de novo.
