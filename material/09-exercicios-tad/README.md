# Módulo 09 — Exercícios de TAD

**Objetivo:** praticar uso e construção de TADs com os TADs-base fornecidos (Conjunto, Data, Horário, Instante, Matriz, Altura).

## Ordem de estudo
1. [Lista de exercícios de TAD](01-lista-de-exercicios-tad.md) — começa pelo problema das férias com o TAD Conjunto.
2. [Enunciado: TAD Conjunto (férias da família)](02-enunciado-tad-conjunto-ferias.md) — **caiu no simulado da AV1 (Questão 2)**.
3. [Lista didática V3](03-lista-didatica-v3.md) — contratos dos TADs-base + 4 módulos:
   - Módulo 1: TADs simples (Altura, Massa)
   - Módulo 2: TADs compostos (Instante, RegistroTemperatura, EscalaTrabalho, Bagagem)
   - Módulo 3: aplicações práticas com `main` e dados de teste
   - Módulo 4: aplicações com TAD Conjunto e TAD Matriz
4. [Aplicação do TAD Instante: validador de conflito de agenda](04-aplicacao-tad-instante-agenda.md)
