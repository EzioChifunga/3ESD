# Matrizes e funções

**Modo:** ▶ Executar

## O que este exemplo mostra
- Declaração e inicialização de matriz: `int m[LIN][COL]`.
- Como passar matriz para função: o número de **colunas** precisa aparecer no parâmetro (`int m[][COL]`).
- Percorrer por linha e por coluna com dois `for` aninhados.
