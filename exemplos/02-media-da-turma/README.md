# Vetores paralelos: média da turma

**Modo:** ▶ Executar

## O que este exemplo mostra
O problema do início do módulo 02: para saber quem está acima da média da **turma**, é preciso guardar os dados de **todos** os alunos antes. Solução: **vetores paralelos** — a posição `i` de `matr`, `n1`, `n2`, `n3` e `media` é sempre do mesmo aluno.

## Como usar
1. **▶ Executar**.
2. Para cada aluno digite a matrícula e as 3 notas numa linha, por exemplo `1010 7.5 8.5 7.8`, e aperte Enter.

## Experimente
- Mude `N_ALUNOS` para 6.
- Troque `n1`, `n2`, `n3` por uma **matriz** `notas[N_ALUNOS][3]` (veja o exemplo *Matrizes e funções*).
