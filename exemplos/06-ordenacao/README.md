# Ordenação: bolha, seleção e inserção

**Modo:** 🐞 Depurar (ou ▶ Executar para ver as passadas)

## O que este exemplo mostra
- **Bolha (bubble sort)**: troca vizinhos fora de ordem; o maior "sobe" para o fim a cada passada.
- **Seleção**: procura o menor do restante e coloca na posição certa.
- **Inserção**: insere cada elemento na parte já ordenada (como cartas na mão).
- Cada passada é impressa para você comparar a estratégia de cada método.

## Como usar
1. **▶ Executar** e compare as passadas dos três métodos.
2. **🐞 Depurar** com ponto de parada dentro de `insercao`; em **Observar**, `v[0]@6` mostra o vetor inteiro a cada passo.
