# Pilha sequencial: parênteses balanceados

**Modo:** ▶ Executar

## O que este exemplo mostra
- **Pilha sequencial**: vetor + índice do topo. Empilhar e desempilhar só no topo (**LIFO**).
- Uma aplicação clássica: estruturas **aninhadas** — o último que abriu tem que ser o primeiro a fechar.
- Os casos de erro: fechar sem ter aberto (pilha vazia), fechar com o tipo errado, sobrar aberto no fim.

## Como usar
**▶ Executar** e digite expressões, uma por linha, por exemplo `{ v[(i+1)] = (a*b); }` ou `(a + b]`.
Use **Fim da entrada** para terminar.
